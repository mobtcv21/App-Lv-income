# App Lv.income

เว็บแอปส่วนตัวสำหรับติดตามรายได้

## ตัวนับเงินที่หาได้

หน้าหลักแสดงยอดเงินที่หาได้ตั้งแต่เงินเดือนเข้ารอบล่าสุด นับขึ้นแบบเรียลไทม์ และดูอัตราได้ทั้งต่อวินาที ต่อชั่วโมง และต่อวัน

- อัตรา = เงินเดือน ÷ ความยาวรอบ โดยรอบเริ่มตอนกดรีเซ็ต และจบวันที่เดียวกันของเดือนถัดไป
- กด "เงินเดือนเข้าแล้ว รีเซ็ตเลย" เมื่อเงินเดือนเข้า ตัวนับจะเริ่มใหม่
- รายได้เสริม/โบนัส: บันทึกเป็นรายการ (ชื่อ จำนวน วันที่) บวกเข้ายอดหลักของรอบทันที แต่ไม่เปลี่ยนอัตรา ซึ่งคิดจากเงินเดือนอย่างเดียว ใต้ยอดหลักมีแถบสองสีแยกเงินเดือนกับเงินพิเศษ พร้อมบาทและเปอร์เซ็นต์
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์ ไม่ต้องล็อกอิน
- เป็น PWA: เปิดใน Safari แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" จะมีไอคอนและเปิดเต็มจอ

เป็น HTML/CSS/JavaScript ล้วน ไม่ต้อง build เปิดผ่านเว็บเซิร์ฟเวอร์ธรรมดาได้เลย เช่น `python3 -m http.server`

## พอร์ตลงทุน

แท็บ "พอร์ตลงทุน" แสดงมูลค่าพอร์ต กำไรขาดทุนเป็นบาทและเปอร์เซ็นต์ และสัดส่วนของแต่ละรายการ จำนวนหน่วยและต้นทุนเฉลี่ยกรอกเองและเก็บในเบราว์เซอร์เท่านั้น

ราคามาจาก `prices.json` ซึ่ง workflow Deploy to GitHub Pages สร้างใหม่ตอน deploy ทุกครั้ง (ทุกชั่วโมง 10:05–17:05 วันจันทร์ถึงศุกร์ และ 20:30 ทุกวัน) ด้วย `scripts/fetch-prices.mjs`

- USD/THB: Yahoo Finance `THB=X` สำรองด้วย open.er-api.com
- ทองคำ XAU/USD ต่อออนซ์: gold-api.com สำรองด้วย Yahoo `GC=F` (ราคาฟิวเจอร์ส)
- KKP US500-UH-E: NAV จาก SEC Open Data API ต้องสมัครคีย์ฟรีที่ https://api-portal.sec.or.th แล้วใส่เป็น repository secret ชื่อ `SEC_API_KEY` ถ้ายังไม่มีคีย์ ให้กรอกราคาเองในแอป

แหล่งไหนดึงไม่ได้ จะใช้ราคาล่าสุดที่เคยได้แทน
